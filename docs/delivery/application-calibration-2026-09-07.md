# 应用目录与下载字段校准

## 当前范围

应用营销目的暂不支持执行。测试账户没有可用的应用优化目标，编辑器禁用该选项，编译器拒绝应用路径。已有草稿仍可查看。

## 已实现

- Connector 分页读取 `/superior/api/v2/agw/ad/get_app_list_for_ebp`，以 `app_cloud_id` 保存 `application` 对象。
- 保存包标识、包名和版本等元数据。该目录只代表安卓应用，不代表 iOS、鸿蒙或预约应用。
- 新迁移 `20260907173000_add_application_object_kind.up.sql` 扩展对象类型约束。
- 应用选择和手动下载链接共用应用引用。切换场景或载体时清除应用引用与优化目标。
- Runner 按精确应用 ID 选择应用包，并核对下载 URL、名称及包元数据。等待解析稳定后回读；同一已解析链接可重复准备。

## 验证与限制

目录读取、应用选择、场景切换和已解析链接回读已验证。目录、编译器、迁移及相关浏览器测试通过。

任意新链接的远端解析成功、应用专属优化目标和最终提交尚未验收。不得将目录可用视为应用投放全链路可用。
