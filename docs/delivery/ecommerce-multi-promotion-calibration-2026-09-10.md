2026-09-10 完成一个项目和两个独立单元的真实创建链路。项目先创建并确认映射，后续配置版本复用该项目，不重复创建。

## 本次修复

- 电商手动投放的出价属于单元，不能写入项目预算。金额定位限定最近字段行，兼容 `oc-row` 与 `b-row`，要求唯一输入框。
- 基础素材支持视频和图片集合，逐项复核 ID 与选中数量，防止同数量错选或跨单元继承。
- 素材抽屉只使用可见搜索框。目标不在初始页时，按 ID 搜索，再核对卡片身份。
- 内置下单目标在平台保存为代码 `20`，写后核验使用该平台代码。
- 项目已创建但该目标字段核验不一致时，可使用严格限定的只读复核恢复，不重新提交项目。其他漂移仍保留。
- 已取消或安全失败的准备允许重新尝试；旧运行及证据保留。Run 幂等键绑定业务执行与请求，避免取消后的新尝试与旧 Run 冲突。
- 等待确认时，过期租约可通过界面重新取得；恢复后清除勾选状态，仍需重新核对并最终确认。

## 橙子落地页目录

电商候选来自 `/superior/api/v2/ad/get_orange_landing_page`，使用 `external_action=20`、`convert_target_for_check=20` 和 `filter_dpa=1`。不再混入第三方落地页列表，也不添加多留资专用 `multi_asset_types`。

目录分页收集，并分别记录电商与多留资适用目标。只有全部查询和分页成功，才替换旧目录；中途失败保留原目录。编辑器读取完整分页，按当前优化目标筛选。

## 仍保留的边界

每个对象的最终保存需要当前确认。第二单元只有在第一单元保存并确认 ID 后才进入 Prepare。结果不明时只能查询，不重试保存。

这次成功仅证明已校准的电商手动投放配置，不证明其他营销目的、投放模式或字段组合全部可用。平台权限、资源资格、页面变化和动态校验仍可能阻止执行。
